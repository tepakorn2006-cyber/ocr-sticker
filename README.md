# เลข 10 หลัก → Word สติกเกอร์

เว็บพิมพ์หรือวางเบอร์โทร 10 หลัก แล้วสร้างไฟล์ Word สำหรับพิมพ์ลงกระดาษสติกเกอร์ A4 (หนึ่งเบอร์ต่อหนึ่งดวง) ทำงานในเบราว์เซอร์ทั้งหมด ข้อมูลไม่ถูกส่งไปที่ไหน

- ใช้งานจริง: https://tepakorn2006-cyber.github.io/ocr-sticker/
- รันในเครื่อง: `npx http-server . -p 8766 -c-1` แล้วเปิด http://localhost:8766 (เปิดไฟล์ `index.html` ตรง ๆ ไม่ได้)
- ทดสอบ: `node tests/test-pure.js`
- สำหรับ AI/นักพัฒนาที่จะพัฒนาต่อ: อ่าน [AGENTS.md](AGENTS.md)
- เวอร์ชันเดิมที่อ่านเลขจากรูปด้วย OCR ยังอยู่ใน git ที่ commit `aafcbf3`

สร้างไฟล์ PDF (แนะนำสำหรับพิมพ์ โดยเฉพาะจากมือถือ) และไฟล์ Word (.docx) ด้วย JSZip มีช่องไฟระหว่างดวงให้ตัดได้ (ค่าเริ่มต้น 3 มม.) และเลือกขนาดตัวเลข ปกติ / ใหญ่ / ใหญ่มาก ได้ (ตัวใหญ่ขึ้นแต่บีบความกว้างให้พอดีดวง) และปรับขนาดดวงทั้งดวงด้วยแถบเลื่อน 50–200% พร้อมดูตัวอย่างก่อนสร้างไฟล์
